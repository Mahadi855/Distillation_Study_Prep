# Distillation Study Prep

A bilingual (English + বাংলা) study guide on **model distillation**: knowledge distillation, RAG, ML and LLM fundamentals, education AI, and quick Q&A for revision.

**Live site:** https://mahadi855.github.io/Distillation_Study_Prep/

## What is inside

- 364 topics in 17 modules (ML foundations, losses and metrics, LLM evaluation, transformers, compression, knowledge distillation, RAG, prompting, education AI, responsible AI, maths, coding and system design)
- 1,600+ short questions and answers, each with a Bangla version
- 107-term bilingual glossary
- 21 interactive widgets (temperature, KL direction, LoRA rank, quantisation, attention, decoding, memory maths and more)
- Works on phone and desktop, light and dark theme

## How to use it

Open `index.html` in a browser, or use the live site above. No install or internet is needed after the files are downloaded.

## Notes

This is study material. Some facts about tools and models change quickly, so check anything marked as unverified before relying on it.
